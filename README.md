# 🧠 Cloud-Based EEG Digital Twin Framework for Real-Time Mental Health Monitoring

A Machine Learning based EEG Digital Twin system designed for real-time mental health monitoring using EEG signal processing, feature extraction, SVM classification, and cloud-based integration.

---

## 📌 Project Overview

Mental health disorders are becoming increasingly common, but traditional assessment methods often depend on manual observation and delayed diagnosis.

This project introduces a **Cloud-Based EEG Digital Twin Framework** that continuously analyzes EEG signals and creates a virtual representation (Digital Twin) of a patient's mental state for real-time monitoring and prediction.

---

## 🚀 Key Features

✅ EEG signal preprocessing  
✅ Noise and artifact removal  
✅ Spectral feature extraction  
✅ Functional connectivity analysis  
✅ Support Vector Machine (SVM) classification  
✅ Digital Twin implementation  
✅ Cloud API integration  
✅ Real-time dashboard monitoring  
✅ Machine learning prediction system

## ⚙ Installation

Clone repository:

```bash
git clone https://github.com/luvneetverma/EEG-Digital-Twin.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run project:

```bash
python run_all.py
```
